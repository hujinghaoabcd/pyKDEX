# pyKDEX 中文概览

pyKDEX 是普通空间、时空、路网及时空路网核密度估计的统一 Python
框架。当前已实现普通空间 KDE、普通时空 KDE、径向与热方程路网 KDE，
以及定义在有测度 arixel 支撑上的固定与自适应带宽时空路网 KDE。处理后的
路网和路网时空工作空间还可保存为带版本、校验和且不使用 pickle 的本地
归档或目录。

0.0.15 版本新增暴露量场、暴露量校正事件率，以及共享固定带宽的病例—对照
相对风险估计。所有计算都绑定真实网格面积、lixel 长度或 arixel 时空测度，
零分母必须采用显式策略处理，不会自动加入 epsilon 或伪计数。
